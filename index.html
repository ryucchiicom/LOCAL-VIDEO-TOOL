無劣化メディアカッター

動画の最初／最後から、指定した長さを切り出す。再エンコードせず、画質・音質を保ったまま保存。

動画ファイルを選択、またはここにドラッグ＆ドロップ MP4 / MOV / WebM / MKV / AVI / WMV / MPEG / TS / 3GP など

切り出し設定

どちら側から切り出す？
初期値は30 FPS。必要なら動画のFPSに合わせて変更してね。
プレビューの動き
「最初から」では切り出し範囲の最後のフレーム、「最後から」では切り出し範囲の最初のフレームへ自動で移動するよ。数値を変えるとプレビューも更新される。
無劣化を優先するため、出力は再エンコードなし（ストリームコピー）。H.264 / HEVC など一般的な動画では、実際の開始・終了位置がキーフレームに合わせてずれることがあり、任意の1フレームぴったりは保証できないよ。

対応形式・プライバシーについて

処理にはブラウザ内で動くFFmpeg WebAssemblyを使うよ。一般的な動画コンテナ／コーデックの多くを扱えるけど、ビルドに含まれないコーデックや壊れたファイルは処理できないことがある。ブラウザが直接再生できない形式では、エンジン準備後に静止画プレビューを試すよ。

初回はFFmpeg本体（約30MB以上）をCDNから読み込むため、ネット接続が必要。動画そのものはサーバーにアップロードせず、端末内で処理するよ。大きなファイルはメモリ不足になる場合があるので注意。
